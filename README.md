# 🚀 RUM (Real User Monitoring) & Core Web Vitals Dashboard

یک سیستم پایش عملکرد وب (RUM) که به‌طور اختصاصی برای اندازه‌گیری و تحلیل شاخص‌های **Core Web Vitals** در اپلیکیشن‌های React/Vite طراحی شده است. این پروژه با هدف تبدیل داده‌های خامِ عملکردِ مرورگر به تحلیل‌های قابل فهم برای بهینه‌سازی تجربه کاربری (UX) توسعه یافته است.

---

## 🎯 اهداف پروژه
- **پایش لحظه‌ای (Real-time):** مانیتورینگ دقیق متریک‌های عملکردی کاربران واقعی در محیط Production.
- **تحلیل داده‌محور:** شناسایی گلوگاه‌های سرعت (Bottlenecks) با استفاده از داشبوردهای بصری.
- **تضمین کیفیت:** پیاده‌سازی مکانیزم Performance Budgeting برای جلوگیری از افت کیفیت در توسعه‌های آتی.

---

## 🏗 معماری فنی (Technical Architecture)
این پروژه از ساختار Feature-based برای ماژولار بودن استفاده می‌کند:
- **`RumProvider`**: هسته مرکزی مانیتورینگ که با استفاده از `web-vitals` و `Context API` داده‌ها را جمع‌آوری می‌کند.
- **`WebVitalMonitor`**: کامپوننت اختصاصی برای نمایش لحظه‌ای داده‌ها.
- **`Features`**: تفکیک لاجیک داشبورد، مدیریت خطا و صفحات اصلی.
- **`Shared`**: شامل سرویس‌های اشتراکی، تایپ‌های مشترک (`vitals.ts`) و لاجیک‌های جهانی.

---

## 📊 شاخص‌های مانیتور شده
این سیستم شاخص‌های حیاتی زیر را ردیابی می‌کند:
*   **LCP (Largest Contentful Paint):** بارگذاری محتوای اصلی.
*   **INP (Interaction to Next Paint):** پاسخگویی به تعاملات کاربر.
*   **CLS (Cumulative Layout Shift):** پایداری بصری صفحه.

---

## 🛠 ابزارهای استفاده شده
*   **Core:** React 18, TypeScript, Vite.
*   **Monitoring:** `web-vitals` library (Attribution build).
*   **Routing:** React Router.
